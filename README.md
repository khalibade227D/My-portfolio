# Khalifa Abdullahi Umar — Portfolio

A responsive React portfolio built with Vite, Tailwind CSS, Framer Motion, and React Three Fiber.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
1. Extract the ZIP.
2. Open the extracted `khalifa-portfolio` folder in VS Code.
3. Open a terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address Vite prints, usually `http://localhost:5173`.

## Build for deployment
```bash
npm run build
npm run preview
```
The production website is generated in the `dist` folder.

## Before publishing
- Replace `hello@example.com` in `src/App.jsx` with your real public contact email.
- Add your real GitHub and LinkedIn profile URLs in the `socialLinks` array in `src/App.jsx`.
- Confirm that every project description and skill reflects what you can confidently discuss.
- The portfolio intentionally leaves out private details such as health information and home address.

## Included
- Your supplied logo in `public/images/khalifa-logo.png`
- Animated 3D star field and floating geometric forms
- Responsive mobile navigation
- Hero, about, skills, projects, journey, and contact sections
- Project cards for your railway booking system, FamilyVault, QR Code Generator, and Daily Tech Briefing concept
- Motion effects and reduced-motion support
